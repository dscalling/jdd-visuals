# Galerie – Bilder hochladen

Du musst nur deine Bilder in den passenden Ordner legen.

- `logo-branding/` → `01.jpg`, `02.jpg`, `03.jpg` ...
- `thumbnails/` → `01.jpg`, `02.jpg`, `03.jpg` ...
- `websites/` → `01.jpg`, `02.jpg`, `03.jpg` ...

Auch `.jpeg`, `.png` und `.webp` werden unterstützt.

Die Website prüft automatisch die Nummern 01–18. Nicht vorhandene Bilder werden einfach nicht angezeigt.
